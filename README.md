# Бот оприходования для ROSTA

Голосом диктуешь закупки, бот ведёт список и по кнопке «Завершить» присылает PDF: Наименование | Кол-во | Закупочная цена | Сумма.

Переменные окружения: BOT_TOKEN, OPENAI_API_KEY, ALLOWED_USER_IDS (Telegram ID через запятую), DATA_DIR (папка для данных, на Railway — путь к volume).
